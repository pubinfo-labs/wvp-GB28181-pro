# WVP-PRO 本地运行文档

> 环境：macOS ｜ 项目根目录：`wvp-GB28181-pro`
> 流程：准备基础服务 → 修改配置 → 启动前端 + 后端

`doc-pub/local/` 目录说明：

```
local/
├── 本地运行文档.md          # 本文档
└── zlm/
    ├── docker-compose-zlm.yml   # ZLMediaKit 容器编排
    ├── config.ini               # ZLMediaKit 配置
    └── record/                  # 录像输出目录
```

## 步骤 1：准备数据库、Redis、ZLMediaKit

### 1.1 MySQL

准备一个 MySQL 8 实例（本机或远程均可），新建数据库并执行初始化脚本：

```sql
-- 新建数据库（字符集 utf8mb4）
CREATE DATABASE IF NOT EXISTS wvp274 DEFAULT CHARSET utf8mb4;
```

```bash
# 执行初始化脚本（脚本位于 数据库/2.7.4/初始化-mysql-2.7.4.sql）
mysql -h <数据库主机> -P <端口> -u <用户名> -p wvp274 < 数据库/2.7.4/初始化-mysql-2.7.4.sql
```

> 脚本已包含建表与默认账号数据；升级场景用 `数据库/2.7.4/更新-mysql-2.7.4.sql`。

### 1.2 Redis

准备一个 Redis 服务，确认其访问密码，与步骤 2 配置中的 `spring.data.redis.password` 保持一致。

### 1.3 ZLMediaKit（docker-compose）

配置文件与 compose 同在 `local/zlm/` 目录下，compose 以相对路径 `./config.ini` 挂载，录像目录为 `./record`。启动容器：

```bash
cd doc-pub/local/zlm
docker compose -f docker-compose-zlm.yml up -d
```

compose 已按 macOS 适配为 **bridge + 端口映射**（macOS 的 Docker 不支持 host 网络）：

| 端口 | 协议 | 用途 |
|------|------|------|
| 6080 | TCP | ZLM HTTP / API（容器 80） |
| 10001 | TCP | RTMP |
| 10002 | TCP | RTSP |
| 10003 | TCP | RTP 单端口 |
| 30000-30500 | UDP + TCP | 国标多端口 RTP（TCP 供设备被动收流） |

`zlm/config.ini` 中需要保证的关键项：

```ini
[api]
secret=<自定义密钥>            ; 要与后端配置 media.secret 一致

[general]
mediaServerId=zlmediakit-local ; 要与后端配置 media.id 一致

[http]
port=80                        ; 容器内端口，映射到宿主 6080

[rtp_proxy]
port=10003
port_range=30000-30500         ; 要与后端 media.rtp.port-range 一致

[hook]
enable=1
; 容器访问宿主机要用 host.docker.internal，不能用 127.0.0.1
on_server_started=http://host.docker.internal:18080/index/hook/on_server_started
on_publish=http://host.docker.internal:18080/index/hook/on_publish
on_play=http://host.docker.internal:18080/index/hook/on_play
on_stream_changed=http://host.docker.internal:18080/index/hook/on_stream_changed
```

## 步骤 2：修改配置信息

后端本地配置在 `src/main/resources/application-local.yml`，并确保 `src/main/resources/application.yml` 中：

```yaml
spring:
  profiles:
    active: local
```

`application-local.yml` 需改的关键项（按实际环境填写）：

```yaml
server:
  port: 18080                    # 后端端口

spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/wvp274?useUnicode=true&characterEncoding=UTF8&serverTimezone=PRC&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: Root_123           # 改成你的 MySQL 账号口令
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      database: 7                # 使用 db7
      password: redis            # 与步骤 1.2 一致

sip:
  port: 8116
  domain: 4101050000
  id: 41010500002000000001
  password: wvp_sip_password
  ip: 172.16.33.171              # ★ 填本机与摄像头同网段的网卡 IP

jt1078:
  enable: true
  port: 21078
  password: admin123

media:
  id: zlmediakit-local           # 与 config.ini 的 mediaServerId 一致
  ip: 172.16.33.171
  hook-ip: host.docker.internal  # ★ 容器回调宿主，必须用这个
  http-port: 6080                # 对应 compose 映射的 6080
  secret: <与 config.ini 的 [api] secret 一致>
  sdp-ip: 172.16.33.171          # ★ 摄像头能访问到的 IP
  stream-ip: 172.16.33.171       # ★ 播放流地址使用的 IP
  rtp:
    enable: true
    port-range: 30000,30500      # 与 config.ini 的 port_range 一致
```

> 关键点：
> - `sip.ip` / `media.sdp-ip` / `media.stream-ip` 填**本机与摄像头同网段的 IP**，不能留空或填 `0.0.0.0`，否则设备管理页「接入信息」会列出多个网卡、摄像头无法接入。
> - `media.hook-ip` 必须是 `host.docker.internal`（容器访问不到宿主的 `127.0.0.1`）。
> - `secret` / `id` / 端口范围三处，前后端要一一对应。

## 步骤 3：启动项目（后端 + 前端）

### 3.1 启动后端

- **IDE 运行**：直接运行主类 `com.genersoft.iot.vmp.VManageBootstrap`（profile 已为 local）。
- **命令行运行**：

  ```bash
  java -jar target/wvp-pro-*.jar --spring.profiles.active=local
  ```

启动成功标志（约 20~30 秒）：

- 日志出现 `Started VManageBootstrap`
- 日志出现 `SIP SERVER` 监听信息
- 日志出现 `服务:JT808 Server 启动成功, port:21078`

### 3.2 启动前端

```bash
cd web
npm install        # 首次
npm run dev        # 默认端口 9528
```

浏览器访问 `http://localhost:9528`，默认账号 `admin` / `admin`。

## 验证

```bash
# 各服务端口
lsof -nP -iTCP -sTCP:LISTEN | grep -E ':(9528|18080|6080|3306|6379)\b'
lsof -nP -iTCP:8116   -sTCP:LISTEN     # SIP，应绑在本机网卡 IP 上
lsof -nP -iTCP:21078  -sTCP:LISTEN     # JT1078

docker ps --filter name=wvp-zlm        # ZLM 容器
```

- 前端：`curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:9528/` 期望 `200`
- 后端根路径返回 500 属正常（前端不在后端里，页面统一走 9528）
- 管理页「设备管理 → 国标接入服务」应显示本机网卡 IP，「媒体节点管理」中 ZLM 节点为在线
